# MediNavi Automatic Location and Hospital Routes

메디네비: 현재 위치와 병원 사이의 자동차 경로를 보여주는 웹사이트입니다.
실행에 필요한 화면·코드·병원 데이터를 모두 **이 medinavi 폴더 바로 아래**에 모았습니다.

## 먼저 알아둘 점

- GitHub 주소는 코드를 보관하는 주소입니다. 웹사이트를 직접 실행하는 주소는 아닙니다.
- 아래 순서로 서버를 실행한 뒤 브라우저를 열어야 지도가 나옵니다. HTML 파일만 더블클릭하지 않습니다.
- 팀장님이 추가한 `app.py`를 실행 기준으로 사용합니다. 별도의 `server.py`는 필요하지 않습니다.
- 실제 `.env`는 공유하지 않습니다. 각 실행 환경에 인증정보를 별도로 설정합니다.

## 파일별 역할

| 파일 | 역할 |
| --- | --- |
| `app.py` | 화면과 JSON을 전달하고, 네이버 길찾기 API에 거리·시간·도로 경로를 요청하는 서버 |
| `index.html` | 지도·위치 버튼·병원 목록·상세정보를 배치한 화면과 모바일 스타일 |
| `map.js` | 팀장님 기존 지도·병원 조회·현재 위치·거리 조회 기능. 추가 기능을 부르는 연결 코드만 추가 |
| `hospital-route-view.js` | 초록 병원 핀, 빨간 현재 위치 점 유지, 경로선, 시간·거리 상자, 방문 시 위치 요청 |
| `hospitals.json` | 강원 23개 의료기관의 저장된 조회결과. 원본 항목명·값·출처·조회 시점 유지 |
| `requirements.txt` | Python 실행에 필요한 라이브러리 목록 |
| `.env.example` | 인증정보 이름만 적은 빈 양식 |
| `.gitignore` | 인증정보·가상환경·로그를 Git 업로드 대상에서 제외하는 설정 |
| `README.md` | 이 실행 및 인수인계 안내서 |
| `server.ipynb` | 팀장님 원본 노트북 보존본. 과거 하위 폴더 경로가 들어 있으므로 현재 구성은 `app.py`로 실행 |

## 내 컴퓨터에서 처음 실행하기

Python이 설치된 Windows 기준입니다. VS Code에서 **medinavi 폴더**를 열고 터미널을 엽니다.

1. 가상환경을 만들고 라이브러리를 설치합니다. 가상환경은 이 프로젝트 전용 도구 보관함입니다.

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

2. 아직 `.env`가 없다면 `.env.example`을 복사하여 이름을 `.env`로 바꿉니다. 기존 `.env`가 있으면 덮어쓰지 않습니다.

   - `NAVER_MAPS_CLIENT_ID`: 네이버 Maps 인증 ID
   - `NAVER_MAPS_CLIENT_SECRET`: 네이버 Maps 인증 비밀키
   - 파일 이름은 `.env`이며 `.env.txt`가 아닙니다. 실제 값은 GitHub·채팅·화면 코드에 넣지 않습니다.
   - 배포 서버에서는 같은 이름의 환경변수를 설정할 수도 있습니다.

3. 서버를 실행합니다.

   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000 --no-access-log
   ```

4. 실행한 컴퓨터의 크롬에서 [메디네비 열기](http://localhost:8000/)를 엽니다.
   위치 권한을 허용하고 병원을 누르면 경로와 예상 거리·시간이 나옵니다.

서버를 켠 터미널은 열어 둡니다. 종료는 `Ctrl+C`, 다음 실행은 **3번 명령만 다시 입력**하면 됩니다.
실행 중인 서버 코드를 바꿨다면 `Ctrl+C`로 종료한 뒤 다시 실행하고 브라우저도 새로고침합니다.
`--no-access-log`는 사용자의 좌표가 들어 있는 요청 주소를 접속 로그에 남기지 않도록 하는 옵션입니다.

macOS/Linux에서는 설치·실행 명령의 `.\.venv\Scripts\python.exe` 부분을 `.venv/bin/python`으로 바꿉니다.

## 네이버 Maps와 모바일 연결

- 웹 지도는 `index.html`의 공개 Client ID를 사용합니다. 다른 Maps 애플리케이션을 사용한다면 이 ID와 서버 인증정보도 맞춰야 합니다.
- 해당 Maps 애플리케이션에서 웹 지도와 Directions 5를 사용할 수 있어야 합니다.
- 실제 접속 주소를 네이버 Maps의 Web 서비스 URL에 등록합니다. 로컬 테스트와 공개 사이트 주소는 구분합니다.
- 휴대폰에서 휴대폰 자신의 `localhost`로 접속하면 PC의 서버가 열리지 않습니다.
- 휴대폰 위치 조회는 접근 가능한 HTTPS 사이트에서 확인합니다. 고정 HTTPS 주소와 운영 서버는 별도의 배포 작업입니다.
- 위치 권한은 브라우저·운영체제가 관리합니다. 처음에는 사용자가 허용해야 하며, 코드가 이를 강제로 허용할 수는 없습니다.

## 화면에서 확인할 기능

1. 병원 23곳의 목록과 지도 핀이 보입니다. 좌표가 없는 기관은 목록에 `좌표 없음`, 잘못된 좌표는 `좌표 확인 필요`로 구분합니다.
2. 지도 준비 후 현재 위치를 한 번 요청하고 빨간 점을 표시합니다. 실패하면 `내 위치`로 다시 시도합니다.
3. 핀 또는 목록에서 병원을 선택하면 기관명·유형·주소·응급실 연락처·출처·조회 시점이 나옵니다. 비어 있는 정보는 `확인 필요`로 표시합니다.
4. 위치와 병원이 모두 정해지면 선택한 병원 핀이 초록색으로 약 두 배 커지고, 다른 병원 핀은 숨겨집니다. 빨간 내 위치 점은 유지됩니다.
5. 자동차 경로를 초록 선으로 표시하며 경로 옆 검은 상자에 `약 N분`, `N.Nkm`를 두 줄로 표시합니다. 별도의 길 안내 버튼은 없습니다.
6. 다른 병원을 누르면 이전 경로·상자가 교체됩니다. `전체 보기`를 누르면 경로·상자를 지우고 전체 병원 핀을 다시 보여줍니다.

## 기존 코드와 추가 코드의 경계

- 기준: 팀장님 `app.py`가 포함된 Git 커밋 `9f20743`.
- `map.js`는 기존 줄을 삭제하거나 바꾸지 않고 기능 연결용 12줄만 추가했습니다. 기존 변수명도 유지합니다.
- `index.html`은 추가 JavaScript를 읽는 2줄만 추가했습니다.
- 사용자가 요청한 한 폴더 배치를 위해 `app.py`의 화면·데이터 경로와 정적 파일 제공 부분만 조정했습니다. 기존 병원·길찾기 조회 로직과 응답 항목은 유지합니다.
- `app.py`는 공개할 JavaScript 두 파일만 허용합니다. 같은 폴더에 `.env`가 있어도 웹으로 내려주지 않습니다.
- `hospitals.json`은 기존 파일 그대로 위치만 옮겼습니다. `server.ipynb`와 `requirements.txt`는 변경하지 않았습니다.
- 추가 동작은 `hospital-route-view.js`에 모았습니다. 지도 화면을 바꾸려면 이 파일부터 확인하면 됩니다.

### 새 변수와 연결 함수

| 이름 | 뜻 |
| --- | --- |
| `selectedHospital` | 현재 선택한 병원 |
| `locationMarker` | 기존 빨간 현재 위치 점 |
| `routeLine` / `routeLabel` | 경로선 / 시간·거리 상자 |
| `hospitals` | 기관 ID로 찾을 수 있게 저장한 병원 핀 모음 |
| `register` / `select` | 원본 병원 핀 전달 / 선택 병원 변경 |
| `draw` | 기존 API 응답의 `path`로 경로를 그림 |
| `locationReset` / `locationReady` | 위치 재조회 시 정리 / 조회 완료 후 선택 병원 경로 조회 |
| `showAll` | 이전 경로를 지우고 모든 병원 핀 복원 |

기존 API 응답을 재사용하므로 경로 표시만을 위한 길찾기 API 중복 호출은 추가하지 않습니다.

## 현재 범위와 오류 확인

- 병원 JSON은 저장 당시 정보입니다. 현재 수술 가능 여부·실시간 수용 가능 여부를 판정하는 데이터는 아닙니다.
- 경로는 서버가 `trafast` 옵션으로 요청한 일반 자동차 기준 예상입니다. 구급차 특례 주행이나 주행 중 자동 재탐색은 포함하지 않습니다.
- 지도만 안 뜨면 공개 Client ID와 등록된 웹 주소를, 서버 시작이 안 되면 `.env`와 라이브러리 설치를 확인합니다.
- 위치가 안 나오면 HTTPS/localhost 접속 여부와 브라우저·OS 위치 권한을 확인합니다.
- 이동정보만 안 나오면 서버 화면의 오류 안내와 Directions 인증·이용 설정을 확인합니다.
